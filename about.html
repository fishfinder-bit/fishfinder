🎣 FishFinder

ช่วยค้นหาข้อมูลปลา บันทึกประวัติการตกปลา และดูสถิติของตัวเอง

📌 เกี่ยวกับโปรเจกต์

FishFinder เป็นโปรเจกต์เว็บไซต์ ที่สร้างขึ้นเพื่อฝึกพัฒนาเว็บ ด้วย HTML, CSS และ JavaScript

ภายในเว็บไซต์สามารถค้นหาปลา ดูข้อมูลเหยื่อและช่วงเวลาที่เหมาะสม รวมถึงบันทึกข้อมูลการตกปลา เพื่อนำไปสร้างสถิติใน Dashboard

📊 Dashboard

ดูจำนวนปลา น้ำหนักรวม ปลาที่หนักที่สุด และปลาที่ยาวที่สุด

💻 เทคโนโลยีที่ใช้

HTML CSS JavaScript LocalStorage

🎯 สิ่งที่ได้ฝึกจากโปรเจกต์
